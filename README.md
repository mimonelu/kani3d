# kani3d

積み木感覚でゲーム用ローポリモデルを作る Web 3D モデラー。`.glb` を出力できます。

- 10cm グリッド・45° 回転にスナップする移動／回転／拡縮
- 立方体・球・三角錐・三角柱・四角錐・四角柱・円錐・円柱・くさび
- パレットから色を選択、複数オブジェクトの結合（CSG 和集合＋同一平面の面数削減）
- 専用形式 `.kani` で保存・読み込み、`.glb` 出力、Undo/Redo、自動保存

```
nvm use   # Node 22
npm install
npm run dev
```
操作方法は画面右のショートカット表を参照。開発者向け情報は [CLAUDE.md](CLAUDE.md) と [docs/](docs/)。
