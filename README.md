# kani3d

積み木感覚でゲーム用ローポリモデルを作る Web 3D モデラー。`.glb` を出力できます。

- Tinkercad 風の統合ハンドルで移動／回転／拡縮（5cm・45° 単位でスナップ）
- ポリゴン単位のペイント（立方体は分割数を増やしてマス目単位で塗れる）と単体の面数最適化
- 結合解除、全体表示（カメラフィット）、エディタ表示のフラット / スムーズ切替
- 結合結果の自動検査（穴・内部面・裏返り）と X線表示
- プリミティブ（立方体・球・くさび・柱・錐・パイプ・ドーナツ・星・多面体）と形状オプション（角数・分割数・半球/半分・肉厚など。配置後も変更可）
- パレットから色を選択、複数オブジェクトの結合（CSG 和集合＋同一平面の面数削減）
- 専用形式 `.kani` で保存・読み込み、`.glb` 出力、Undo/Redo、自動保存

```
nvm use   # Node 22
npm install
npm run dev
```
操作方法はツールバー右端の「?」ボタン（または ? キー）のヘルプを参照。開発者向け情報は [CLAUDE.md](CLAUDE.md) と [docs/](docs/)。
